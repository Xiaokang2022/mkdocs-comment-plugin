# 评论插件演示

这是 `mkdocs-comment-plugin` 的本地演示页面。页面底部即为插件注入的评论区。

## 它能做什么

- ✅ **Markdown 评论**：`**粗体**`、`*斜体*`、`` `代码` ``、列表、引用、表格、链接、图片；每条评论右上角的按钮可在渲染结果与 Markdown 原文之间切换
- ✅ **表情互动**：为页面或单条评论点赞 / 送表情，再次点击即可取消（身份取自来源 IP，所以同一台机器只能点一次）
- ✅ **统计信息**：浏览量、评论数、表情数实时回显
- ✅ **楼中楼回复**：一级嵌套，回复回复会自动带上 `@提及`
- ✅ **匿名署名**：不填昵称时显示为「匿名用户」，头像用主题的用户图标；IP 默认对所有访客以淡色小字附在名字旁，便于对照同一出口下的留言
- ✅ **自助删除**：能不能删由来源地址决定（昵称不参与），清掉浏览器数据也还能删自己的评论
- ✅ **「我」标签**：同样按来源地址判定，所以清掉站点数据、换个浏览器依然能认出自己的评论；
  共享出口下则可能把别人的评论当成自己的
- ✅ **逐页开启**：默认一个页面都没有评论区，页面在自己头部写 `comments: true` 才生成

## 示例 Markdown

试着发表一条这样的评论：

```markdown
**很喜欢这个主题！**

> 引用一段话

1. 第一点
2. 第二点

`行内代码` 与 [链接](https://www.mkdocs.org)
```

## 说明

!!! note "后端未启动时"
    如果看到「无法连接评论服务」，说明 `api_base` 指向的后端没有运行。
    先在 `backend/` 目录下启动服务，然后刷新页面。

```bash
cd backend
python -m uvicorn main:app --reload --port 8000
```

插件配置中的 `api_base` 需要与此地址一致（默认 `http://127.0.0.1:8000/api/v1`）。
