# 这一页没有评论区

本页的头部**没有**写 `comments: true`，所以页面底部不会有评论区——也没有任何评论相关的网络请求。

这是插件的默认行为：把组件装到已有的文档站上，不应该让几十个页面突然都长出评论框。
哪一页有评论，由那一页自己决定：

```markdown
---
comments: true
---
```

对比一下：[首页](index.md) 与 [使用指南](guide.md) 都写了这一行，所以它们的页面底部有评论区。

> 常见误解：把 `page_selector` 设成一个在很多页面都命中的选择器（例如 `.md-content__inner`），
> 并不会「只在这几页挂载」。CSS 选择器会在所有命中的页面上生效，
> 那等于整站开启，页面头部的元数据看起来就像没生效一样。
> `page_selector` 现在只决定**在已经开启的页面里渲染到哪个容器**，不再决定是否渲染。
